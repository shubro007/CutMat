About Cutmat

A cutting mat for your images, right in the browser

Cutmat is a free tool for dividing an image into smaller pieces without installing anything. Upload a photo and choose how you want to cut it: pull out one exact region, slice the whole thing into a grid of rows and columns, or drop several independent selections anywhere on the frame. Every crop happens on your own device using the HTML canvas API — nothing is ever sent to a server, so there's no upload wait and no privacy concern with sensitive images.

It's built for the fiddly, repetitive cropping jobs that a single-selection editor makes tedious: cutting a sprite sheet into individual frames, splitting a scanned contact sheet into separate photos, or breaking a wide banner into a nine-image Instagram grid.

How it works

Three ways to cut, one export flow

01 — Standard Crop

Pull one region out

Drag the corner or edge handles to select any rectangle, or type exact X, Y, width, and height values. Good for a single, precise crop.

02 — Grid Slicing

Cut evenly, then adjust

Set a number of rows and columns for an even grid, then drag any individual line to resize a row or column by hand. Add or remove cuts as needed.

03 — Multi-Select

Draw as many boxes as you like

Click and drag anywhere on the image to add a selection. Selections can overlap, and each one moves, resizes, and deletes independently.

FAQ

Good to know

Does my image get uploaded anywhere?

No. Cropping and slicing happen locally in your browser using the canvas API. The image data never leaves your device.

What file types are supported?

Any image format your browser can decode, which typically includes JPG, PNG, and WEBP. Exports are always PNG, unless you turn on a target file size, in which case exports switch to JPEG so the size can be controlled.

Is there a size or resolution limit?

Exports are generated at the original image's full resolution, so a very large source image can take a moment longer to process and zip. There's no hard-coded limit, but performance depends on your device.

Can I get uneven rows or columns in Grid Slicing mode?

Yes. Start from an even grid, then drag any individual dividing line to resize that row or column. Each line moves independently.

Can I control the exported file size in KB or MB?

Yes. Turn on "Target file size" in the Export panel, enter a value like 40 KB or 200 KB, and generate a preview. Cutmat searches for a JPEG quality level that lands close to your target, and will also shrink the image's resolution if quality adjustment alone can't hit a very small target.

Does this work offline?

The core cropping tool works without a network connection once the page is loaded, but the page fetches fonts and the ZIP-export library from a CDN on first load, so you'll need internet access at least once.
